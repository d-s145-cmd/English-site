# English Learning Site

Интерактивный сайт для изучения английского языка (A2–C1) и подготовки к ICPC.
Работает полностью в браузере (без сервера) и разворачивается на GitHub Pages.

---

## Возможности

- Разделы: A2, B1, B2, C1, ICPC.
- Внутри каждого раздела — Теория и Практика.
- **Интерактивная практика:** пользователь вводит ответ, нажимает «Проверить», и сайт автоматически подсвечивает верные (зелёным) и неверные (красным) ответы, показывая общий счёт.
- Добавление новых материалов — через редактирование одного файла `data.js`.

## Как добавить новый материал

Все материалы хранятся в файле `data.js` в массиве `MATERIALS`.

### Шаг 1. Откройте `data.js` на GitHub
Нажмите на файл `data.js` и выберите иконку карандаша (Edit this file).

### Шаг 2. Добавьте объект в конец массива
Найдите закрывающую скобку `];` и перед ней вставьте новый объект. Не забудьте поставить запятую после предыдущего.

#### Для теории (обычный текст):

    {
      id: 107,
      level: "A2",
      category: "theory",
      topic: "new_topic",
      title: "Название темы",
      content: `
        <h3>Заголовок</h3>
        <p>Текст материала.</p>
        <div class="example">
          <div class="en">I have a pen.</div>
          <div class="ru">У меня есть ручка.</div>
        </div>
      `
    },

#### Для интерактивной практики:

Используйте двойные квадратные скобки `[[правильный_ответ]]`, чтобы создать поле ввода:

    {
      id: 212,
      level: "A2",
      category: "practice",
      topic: "new_practice",
      title: "Новая практика",
      content: `
        <p>Вставь пропущенное слово:</p>
        <ol>
          <li>I [[have]] a dog.</li>
          <li>She [[is]] a doctor.</li>
        </ol>
      `
    },

### Шаг 3. Сохраните
Нажмите **Commit changes**. Через 1–2 минуты сайт обновится на GitHub Pages.

---

## Поля объекта

- `id` — уникальный номер (просто увеличивайте на 1).
- `level` — `A2`, `B1`, `B2`, `C1` или `ICPC`.
- `category` — `theory` (теория) или `practice` (практика).
- `topic` — короткое имя темы латиницей, без пробелов.
- `title` — заголовок, который видит пользователь.
- `content` — HTML-разметка материала.

---

## Готовые CSS-классы для контента

В поле `content` можно использовать:

- `<div class="example">…</div>` — блок с примером (голубая полоса слева).
- `<div class="warn">…</div>` — блок с предупреждением (жёлтая полоса слева).
- `<table>…</table>` — таблица.
- `<code>…</code>` — выделение кода.
- `<pre><code>…</code></pre>` — блок кода.

## Публикация на GitHub Pages

1. Откройте настройки репозитория: **Settings**.
2. В левом меню выберите **Pages**.
3. В разделе **Branch** выберите `main` и папку `/ (root)`.
4. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:

       https://d-s145-cmd.github.io/English-site/

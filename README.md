# English Learning Site 📚

Интерактивный сайт для изучения английского языка, а также специализированный раздел для подготовки к олимпиадам по программированию (ICPC).

Сайт работает полностью в браузере (без серверной части) и разворачивается на **GitHub Pages**.

## 🚀 Возможности

*   **Разделы по уровням:** A2, B1, B2, C1 и отдельный блок **ICPC**.
*   **Структура:** Внутри каждого уровня материалы разделены на **Теорию** и **Практику**.
*   **Формат:** Материалы хранятся в формате Markdown и красиво отображаются на сайте.
*   **Простота:** Для добавления материалов не нужно писать код — достаточно отредактировать один файл.

## 🛠️ Структура проекта

```text
english-site/
│
├── index.html          # Главная страница сайта
├── app.js              # Логика работы (навигация, отрисовка)
├── data.js             # ⚠️ БАЗА ДАННЫХ: все материалы хранятся здесь
├── README.md           # Этот файл
└── static/
    └── style.css       # Оформление (шрифты, цвета, кнопки)

💻 Как запустить локально
Скачайте или склонируйте репозиторий.

Откройте файл index.html в любом современном браузере (Chrome, Firefox, Edge).

Всё готово! Сайт работает локально.

(Для удобства разработки можно использовать расширение Live Server в VS Code).

➕ Как добавить новый материал
Все материалы хранятся в файле data.js в виде массива объектов MATERIALS.

Шаг 1: Откройте data.js на GitHub
Нажмите на файл data.js и выберите иконку карандаша (Edit this file).


📝 Стили оформления
В content можно использовать готовые CSS-классы для красивого вывода:

<div class="example">...</div> — блок с примером (голубая полоса слева).

<div class="warn">...</div> — блок с предупреждением/ловушкой (желтая полоса слева).

<table>...</table> — для таблиц.

<code>...</code> — для выделения кода или английских слов.

🌐 Публикация на GitHub Pages
Зайдите в настройки репозитория (Settings).

В левом меню выберите Pages.

В разделе Branch выберите ветку main и папку / (root).

Нажмите Save.

Ссылка на ваш сайт появится через пару минут (вида https://ваш_логин.github.io/название-репозитория/).

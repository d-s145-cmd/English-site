# English Learning Site

Интерактивный сайт для изучения английского языка (A1–C2, EXAM, ICPC).
Работает полностью в браузере (без сервера) и разворачивается на GitHub Pages.
Теперь сайт можно удобно просматривать не только на компьютере, но и на мобильных устройствах.

---

## Возможности

- Уровни: **A1, A2, B1, B2, C1–C2, EXAM, ICPC**.
- Внутри уровня — разделы:
  - **Теория** — объяснения с примерами и таблицами.
  - **Практика** — упражнения с автопроверкой.
  - **Чтение** — тексты с переводом, аудио, вопросами и упражнениями.
  - **Лексика** — словарь с карточками и справочником.
- **Мобильный просмотр** — сайт адаптирован для смартфонов и планшетов: навигация, карточки, таблицы, упражнения и аудиоплеер подстраиваются под ширину экрана.
- **Интерактивная практика:** пользователь вводит ответ, нажимает «Проверить», сайт подсвечивает верные (зелёным) и неверные (красным) ответы и показывает счёт.
- **Словарь:**
  - режим флеш-карточек с интервальным повторением;
  - справочник слов с транскрипцией (IPA);
  - фильтр по уровням.
- **Чтение:** скрытый перевод под спойлером, аудиоплеер, вопросы и упражнения с автопроверкой.
- **Тёмная тема** (Midnight) и светлая (Burgundy), переключатель в шапке.
- **Поиск** по всем материалам с подсветкой совпадений.
- **Прогресс** сохраняется в `localStorage`: пройденные темы, результаты, последняя открытая страница.
- Добавление новых материалов — через редактирование одного файла `data.js`.

## Просмотр на мобильных устройствах

Сайт можно открыть на смартфоне или планшете через обычный мобильный браузер. Отдельное приложение устанавливать не нужно.

Интерфейс адаптируется под небольшие экраны: меню, карточки материалов, таблицы, поля ввода в упражнениях и аудиоплеер в разделе «Чтение» остаются доступными и удобными для использования.

Для просмотра на телефоне достаточно открыть опубликованную ссылку GitHub Pages:
https://d-s145-cmd.github.io/English-site/

## Как добавить новый материал

Все материалы хранятся в файле `data.js` в массиве `MATERIALS`.

### Шаг 1. Откройте `data.js` на GitHub
Нажмите на файл `data.js` и выберите иконку карандаша (Edit this file).

### Шаг 2. Добавьте объект в конец массива

#### Теория
Найдите закрывающую скобку `];` и перед ней вставьте новый объект. Не забудьте поставить запятую после предыдущего.

#### Интерактивная практика

Используйте двойные квадратные скобки `[[правильный_ответ]]`, чтобы создать поле ввода.
Несколько допустимых вариантов разделяйте `|`:

#### Чтение

Карточка чтения использует `category: "reading"`. В `content` обычно входят:

1. Плейсхолдер аудио — `app.js` заменит его на `<audio controls>`:
2. Английский текст под `<h3>English</h3>`.
3. Перевод под `<h3>Перевод</h3>` — в интерфейсе он автоматически скрывается под спойлер «Показать перевод».
4. Новые слова под `<h3>Новые слова</h3>` (таблица English / Русский).
5. Вопросы под `<h3>Questions</h3>` — с `[[ответ]]`, если хотите автопроверку.
6. Упражнение под `<h3>Exercise — …</h3>` — тоже с `[[ответ]]`.

#### Словарь

Карточка `category: "vocabulary"` содержит таблицу `English / Русский`. Слова из неё автоматически попадают в флеш-карточки и справочник.

    
### Шаг 3. Сохраните
Нажмите **Commit changes**. Через 1–2 минуты сайт обновится на GitHub Pages.

## Поля объекта

- `id` — уникальный номер.
- `level` — `A1`, `A2`, `B1`, `B2`, `C1`, `C2`, `EXAM` или `ICPC`. Для `C1`/`C2` в интерфейсе используется общий раздел `C1–C2`.
- `category` — `theory`, `practice`, `reading` или `vocabulary`.
- `topic` — короткое имя темы латиницей, без пробелов.
- `title` — заголовок, который видит пользователь.
- `content` — HTML-разметка материала.

## Готовые CSS-классы для контента

В поле `content` можно использовать:

- `<div class="example">…</div>` — блок с примером (полоса слева).
- `<div class="warn">…</div>` — блок с предупреждением.
- `<table>…</table>` — таблица.
- `<code>…</code>` — выделение кода.
- `<pre><code>…</code></pre>` — блок кода.
- `<div class="audio-placeholder" data-audio="audio/…">…</div>` — плейсхолдер аудио (заменяется на `<audio controls>` в разделе «Чтение»).
- `<details class="translation-toggle">…</details>` — спойлер (используется для скрытия перевода).

## Аудио для раздела «Чтение»

1. Положите MP3 в папку `audio/`.
2. Имя файла должно **точно** совпадать с `data-audio` в карточке.
3. Допустимы только латиница, цифры и дефис, расширение — `.mp3` в нижнем регистре.
4. В карточке `reading` оставьте плейсхолдер:

       <div class="audio-placeholder" data-audio="audio/a1-my-family.mp3">…</div>

5. `app.js` заменит его на `<audio controls src="audio/a1-my-family.mp3">`.

Проверка: откройте напрямую `http://localhost:8000/audio/a1-my-family.mp3`. Если файл играет — путь и имя верны.

## Публикация на GitHub Pages

1. Откройте настройки репозитория: **Settings**.
2. В левом меню выберите **Pages**.
3. В разделе **Branch** выберите `main` и папку `/ (root)`.
4. Нажмите **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу: https://d-s145-cmd.github.io/English-site/

Убедитесь, что папка `audio/` тоже загружена в репозиторий, иначе плеер в разделе «Чтение» не заработает на GitHub Pages.

После публикации сайт можно открыть и на мобильном устройстве: достаточно ввести ту же ссылку в браузере телефона или планшета.
